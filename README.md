# AI-Accelerated Requirement Gathering (VS Code + GitHub Copilot)

This repository provides a standardized, AI-ready template for executing the
**Requirement Gathering phase** of the SDLC using GitHub Copilot in VS Code.

## How to Use

1. Clone this repository or click "Use this template"
2. Open the folder in VS Code
3. Ensure GitHub Copilot extension is enabled
4. Follow the instructions in `prompts.txt`
5. Use Copilot Chat to generate content in each file

## Outcome

- Structured problem definition
- Clear goals and scope
- Engineering-ready PRD
- Sprint-ready user stories
- Testable acceptance criteria

## Intended Benefit

Reduce requirement documentation time by **50%+** while improving consistency and clarity.
